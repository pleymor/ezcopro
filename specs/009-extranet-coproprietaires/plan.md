# Implementation Plan: Extranet Copropriétaires

**Branch**: `009-extranet-coproprietaires` | **Date**: 2025-01-16 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/009-extranet-coproprietaires/spec.md`

## Summary

Créer un espace personnel pour les copropriétaires leur permettant de consulter leur solde, leurs appels de fonds, l'historique des paiements et les documents partagés par le syndic. L'extranet utilise la même URL que l'application syndic avec un routage basé sur le rôle de l'utilisateur connecté (Custom Claims Firebase Auth).

## Technical Context

**Language/Version**: TypeScript 5.6.0 (strict mode enabled)
**Primary Dependencies**: Next.js 15.x, React 19.x, Firebase Auth/Firestore/Storage, Tailwind CSS, Zod, React Hook Form, Radix UI, Lucide React
**Storage**: Firebase Firestore + Firebase Storage (documents, limite 500 Mo/copropriété)
**Testing**: Vitest (unit), Playwright (E2E)
**Target Platform**: Web PWA (responsive, mobile-first)
**Project Type**: Web application (Next.js App Router)
**Performance Goals**: Accès au solde < 10 secondes après connexion
**Constraints**: Limite stockage 500 Mo/copropriété, liens invitation expirent après 7 jours
**Scale/Scope**: 3-30 lots par copropriété, ~100 utilisateurs pilotes MVP
